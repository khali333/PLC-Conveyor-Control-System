# PLC-Conveyor-Control-System
Conveyor belt system built using CODESYS and Ladder Diagrams
Here I have built the conveyor belt project using ladder diagrams, it features a product count, jam alarm and Manual/Auto modes
I've built an HMI visualization and mapped all the variables to their appropriate indicators and buttons
Screenshots of the ladder diagram are provided along with the HMI visuals.
The video demonstration can be accessed here, showcasing the ladder logic and simulation controls for demo purposes. https://youtu.be/MfTsW2H3e5U
